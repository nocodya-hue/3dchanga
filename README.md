# 3DCHANGA · propuesta de web

Web de 3DCHANGA (Alzira, Valencia): diseño y fabricación de piezas únicas en 3D para el mundo de la música. Útiles personalizados y componentes para instrumentos, a medida para músicos, charangas, bandas y orquestas.

**Ver la web:** https://nocodya-hue.github.io/3dchanga/

- HTML, CSS y JavaScript estáticos (GSAP + Lenis para el movimiento), tipografía Inter autoalojada.
- El formulario está en modo de vista previa: no envía nada hasta configurar `FORM_ENDPOINT` en `js/main.js`.

> Web de muestra. El logo es una propuesta creada con IA y redibujada en vectorial. Las imágenes están generadas con IA con su marca, provisionales hasta contar con fotos de sus piezas reales.
